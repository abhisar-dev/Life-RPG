LIFE RPG — CLEAN BUILD

1. Open this folder in VS Code.
2. Terminal 1:
   cd backend
   npm install
   npm run dev
3. Terminal 2:
   cd frontend
   npm install
   npm run dev
4. Open http://localhost:5173 in Chrome/Edge.
5. Keep BOTH terminals running.

If an old Life RPG is already running, press Ctrl+C in its terminals first.
If the browser shows an old/blank page, use Ctrl+Shift+R.
